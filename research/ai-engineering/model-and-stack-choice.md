Which models, products and frameworks to use with AI.

## Practices and patterns

- Jess Martin argues framework choice now follows what LLM base models write well (React over Svelte). — “Svelte is dead because LLM base models are better at writing React.” (main) [@jessmartin, 2024-08-09](https://x.com/jessmartin/status/1822026807643910149)
- Route work by model cost: the expensive model does the hard reasoning and a cheap model makes decisions among options the harness has already prepared and validated. — “the expensive model thinks, the cheap one decides” (main) / “jev chooses from options the harness already prepared and validated” (main) [@0x_rody, 2026-10-17](https://x.com/0x_rody/status/2111491014053511341)
- Let the cheap model score which project notes matter before they are loaded into context. — “scores which project notes matter before the context even loads” (main) [@0x_rody, 2026-10-17](https://x.com/0x_rody/status/2111491014053511341)
- When a tool fails, choose a recovery path instead of retrying blindly, and run focused checks before the full test suite. — “picks a recovery path when a tool fails, so nothing retries blind” (main) / “runs the focused checks before the full test suite” (main) [@0x_rody, 2026-10-17](https://x.com/0x_rody/status/2111491014053511341)
