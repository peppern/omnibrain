## Main Point

Tobi Lütke calls Vercel Labs' gpu-lexer 'so clever': a 27.5KB model that does syntax highlighting on the GPU in the browser.

## Takeaways

- It's language-agnostic: the model guesses each token's type, so no per-language grammar is needed.
- The demo frames show it scanning context in both directions, building a bottom-up then top-down tree so every part gets whole-file context, then classifying all parts in parallel into about 9 token types.
- Runs on WebGPU; released as experimental and built for learning. (Video frames read with vision.)
