## Main Point

Alex Gough Cooper's 49-minute live session argues that ad video editing can now be done entirely by an agent in Claude Code (he uses Opus 5.5) from raw footage and a brief, and shows a three-stage path: prompt edits, turn your feedback into reusable skills, then build a review app that feeds new feedback back into those skills.

## Takeaways

- Beginner level: give Claude Code the brief (his was a Notion page of talking points) and a footage folder, and ask for the edit; he says it one-shots cut-downs with captions and B-roll, with only minor fixes, and no extra editing tools or MCPs are involved.
- Intermediate level: write the team's editing rules (don't cut too tightly, place B-roll at sentence boundaries, follow brand guidelines) into a shared video-editing skill, and seed it by having an agent compile 30 days of reviewer feedback from the Frame review tool.
- He recommends splitting a general editing skill into style-specific skills (UGC, mashup, AI animation), each built from three or four example ads in that style.
- Advanced level: a local review app where he leaves timestamped notes, Claude Code applies them, and any feedback that applies generally is logged to a shared editing-standards markdown file that every skill reads, so the skills improve with use.
- He claims his team saw edit time drop about 67%, but says complex, long or high-production edits aren't there yet, and that skilled editors are still needed to write the rules and check the output.
- The session is partly a promotion: he says the skills will be given to customers of his company's product, Parker.
