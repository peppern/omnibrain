# Handoff Template

## Goal

What this agent or human is trying to accomplish.

## Current State

What is already true right now.

## Key Context

- Important facts
- Definitions
- Constraints
- Prior decisions

## Sources

- Links, file paths, repo refs, or item IDs

## Recommended Next Steps

1. First thing to do
2. Second thing to do
3. Validation or completion step

## Open Questions

- Unknowns that still matter

## Risks

- Ways the next agent could go wrong
